## 餐廳位置
{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-1.jpg" caption="鄉村氣息的三合院建築" >}}


這禮拜天氣大都晴朗，天天都能看見太陽探頭。
在經歷過好幾個星期的陰天、雨天，難得能維持一個星期的好天氣，
假日便免不了要出門一趟，感受下暖陽的氣息~

這間位於桃園楊梅的「鄰長伯大湯圓」是家父推薦的餐廳，
身為客家人的家父，挺喜歡這的「韭菜湯圓」，故帶著我與家母也來品嘗一番。

{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-2.jpg" caption="店外擺著可愛的多肉" >}}

還未進店，家母便被外頭擺著的多肉所吸引(家母很喜歡多肉、食蟲等植物)。
看得出來有特別照顧，才能如此好看。

{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-3.jpg" caption="充滿古早風味的餐廳風格" >}}



{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-4.jpg" caption="睡姿可愛的大橘，人人都能上手摸個一把" >}}

由於提供的是無菜單料理，我們被店員告知要前往廚房點餐，
途中便在大廳裡發現這隻睡得安詳的大橘，忍不住上手摸摸。
很乖巧的大橘，先給牠嗅嗅我的手，見牠不介意我才敢放肆摸摸喵皇。



## 菜色

{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-5.jpg" caption="水煮鴨肉" >}}

本來家父想點的是豬腳，可惜我們比較晚來(下午近兩點)，便只剩下鴨肉。
鴨肉很大份，三個人吃不完，
在廚房點菜的時候，被建議說吃不完回家可以加冬粉下去煮，便又是一餐。

這道鴨肉口感鮮嫩，並不老，皮和肉也容易分離；
單吃或是沾醬油吃都可以，醬油有九層塔作香氣搭配。
不過有些部分油脂較厚，後來包回去煮冬粉，都不需要另外加油~

{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-6.jpg" caption="客家燜筍" >}}

非常道地的客家燜筍，油香卻不過膩，吃來便不會發澀，
咬下去脆嫩爽口，拌著飯吃可以吃好幾口。

{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-7.jpg" caption="芥菜" >}}

芥菜新鮮，煮得軟嫩適中，看著油亮卻不油膩；枸杞點綴，在充滿薑絲的氣息中帶有一絲甘甜。

{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-8.jpg" caption="清炒龍鬚菜" >}}

龍鬚菜新鮮可口，因為嫩所以嘗起來清脆，辣椒與薑絲、蒜末拌炒，只有一絲絲的微辣與蒜香碰撞。

{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-9.jpg" caption="韭菜湯圓" >}}

這道招牌菜韭菜湯圓，確實沒有讓人失望。
有時候我在外面喝湯裡帶有的韭菜碎，有些都是用很老的韭菜，吃起來嗑牙嗑舌嗑喉嚨；
但這道的韭菜碎香又嫩，讓我很願意將韭菜碎一同吃完。

湯裡拌有油蔥，聞著香氣四溢，
湯圓的糯米皮厚薄適中，質地完全不黏牙，也是讓人感嘆；
肉質餡料則是味道甘甜，並無腥味，果真是好吃。



## 評價

{{< figure src="/posts/taiwan-taoyuan-trip-4/trip-taoyuan-4-10.jpg" caption="吃完又跑回去看大橘，牠已成團" >}}


{{< rating score="4" max="5" label="整體評分" >}}

最喜歡的是那道「韭菜湯圓」，
大概因為我算是沒那麼挑，所以其實覺得算好吃。
不過無菜單料理價格偏貴，算是小小缺點，
整體而言是好吃，但並沒有很多驚豔之處，故給四顆星。
