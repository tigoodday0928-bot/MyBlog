## 餐廳位置
![](/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-1.jpg)


{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-2.jpg" caption="假日用餐人潮多，生意很好" >}}


今天一家人到淡水半日遊，午餐決定在這間家父吃過一次的60年代用餐；
這是一間海景餐廳，但很可惜淡水今天霧氣重，沒能看到碧海藍天相輝映的模樣。


## 菜單


{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-3.jpg" caption="菜色種類眾多" >}}


因為只有三個人的關係，並沒有點到很多菜。
總共是一鍋蛤蜊湯、脆皮雞(半隻)、炒娃娃菜一份、檳榔花(涼拌)一份、綜合生魚片一份、川燙鮮蝦一份、五更腸旺一份。
算是為想吃的菜基本上點了一些。



## 菜色


{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-4.jpg" caption="白飯免費續用" >}}


這邊白飯內用是無限續用的，外帶則是10元/碗，點的菜配著飯吃，足夠吃上兩碗，滿足我們飢餓的腸胃。

{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-5.jpg" caption="蛤蜊湯 NT.200" >}}

大概是因為假日人潮很多，意外先上的是蛤蜊湯：蛤蜊肉大，本身是帶有鹹味的，故而湯頭便是簡單的調味，搭配適宜。

{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-6.jpg" caption="脆皮雞(半隻) NT.370" >}}


家父吃過的脆皮雞，是招牌菜之一。剛上桌便淺嘗一口，外皮酥脆，如果是雞皮愛好者會喜歡；
內裡肉質鮮嫩，鮮美的肉汁被很好的鎖在了裡面，因為很燙還必須一邊吹涼才能再吃。

{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-7.jpg" caption="涼拌檳榔花 NT.220" >}}

這道涼拌檳榔花是我很喜歡的一道菜，蒜味很足，帶有一絲絲微辣，非常下飯，令我拌著吃了兩碗飯。

{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-8.jpg" caption="川燙鮮蝦 NT.180" >}}

蝦子肉質鮮彈、味道甜美，剝殼很輕鬆，不論是沾著醬油芥末或是直接入口，都很新鮮。



{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-9.jpg" caption="五更腸旺 NT.160" >}}

對於不擅吃辣的我而言，這道算是有點小辣；鴨血不腥、軟嫩，酸菜爽口，比較可惜的是腸子有些過老。
怕辣的話只要醬汁別撈太多就行，適合下飯吃。

{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-10.jpg" caption="清炒娃娃菜 NT.130" >}}

與蒜頭清炒的娃娃菜，蒜味並不重，娃娃菜本身是屬於比較硬的品種，算是普通的一道菜。

{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-11.jpg" caption="綜合生魚片 NT.290" >}}

身為生魚片愛好者，鄰近海邊便忍不住點了一份來嚐嚐。
整體來說是新鮮的，鮭魚普通，鮪魚鮮彈，紅魽軟嫩易入口，尼信略腥、彈牙；
最喜歡的應該是紅魽的部分，因為鮪魚吃的時候結冰還沒化，我的敏感性牙齒直接哀號。

{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-12.jpg" caption="炸冰淇淋 NT.160" >}}

這份炸冰淇淋是送的，總共五個：
口味有芋頭、花生、香草，怎麼安排口味不曉得，得咬一口才知道，有點像拆盲盒的驚喜感。
很剛好家父吃到芋頭，家母吃到花生與香草，我則吃了兩顆香草(牙齒哀號)。
外層油炸的皮酥脆但略顯油膩，內裡冰淇淋分量適宜，不多不少，當飯後甜點還是很不錯的。



## 評價


{{< figure src="/posts/taiwan-newtaipei-trip-2/trip-newtaipei-2-14.jpg" caption="餐廳後面往海灘的小徑" >}}


{{< rating score="4.5" max="5" label="整體評分" >}}

每道菜都很新鮮味美，招牌菜脆皮雞必吃經典！
可惜人不夠多，可能要以後才有機會再來品嘗其他道菜，
涼拌檳榔花令我這個重口愛好者回家後仍念念不忘。
